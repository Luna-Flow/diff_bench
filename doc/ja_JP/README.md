# diff_bench ドキュメント

`diff_bench` は Luna-Flow MoonBit パッケージの差分正当性・性能ベンチマークを収録します。

`floating_vs_decmial_x` は GitHub 上の参考用ベンチマークです。Mooncakes には公開せず、下流ランタイム依存としては想定しません。

## Structure

- `CONTRIBUTING.md`: コントリビューション規約とリリース確認項目
- `doc_standard.md`: ドキュメント要件
- `core/api.md`: 公開 API リファレンス
- `core/tutorial.md`: 利用チュートリアル
- `core/design.md`: 実装と設計メモ
- `floating_vs_decmial_x/api.md`: ベンチマーク API と実行入口
- `floating_vs_decmial_x/tutorial.md`: 再現手順
- `floating_vs_decmial_x/design.md`: 設計と性能レポート
- `floating_vs_decmial_x/performance.md`: 多言語パフォーマンス分析レポート
- `dzmingli_vs_floating/api.md`: ベンチマーク API と実行入口
- `dzmingli_vs_floating/tutorial.md`: 再現手順
- `dzmingli_vs_floating/design.md`: 正当性・設計レポート
- `dzmingli_vs_floating/performance.md`: 測定性能分析
