# 設計と性能レポート

共通の中立 fixture を使い、現在は `moonbitlang/x/decimal@0.4.46` と `Luna-Flow/floating/decimal_gda@0.7.1` を比較します。準備、検証、変換、正規化は計測外です。`exact_overlap` は共通表現可能な演算、`x_compatible` は X の 28 小数桁・ゼロ方向切り捨てを含む処理を測定します。

結果の要約：加減算は 1–256 桁で GDA、1,024–4,096 桁で X が優位。乗算は X が約 `2.1–2.7×` 高速です。除算は小さい `exact_overlap` 入力では GDA、大きい入力では X が優位で、`x_compatible` は 256 桁までほぼ拮抗し、それ以上では GDA が優位です。比較は GDA が約 `3.4–14.8×` 高速です。いずれも本ワークロード固有の観測です。

固定精度 decimal64/128、BigInt 実装、最適化された C 実装、完全な IEEE/GDA 実装では、それぞれ精度上限、整数アルゴリズム、低レベル最適化、意味機能のコストが結果を左右します。本パッケージは GitHub 専用で Mooncakes には公開しません。
