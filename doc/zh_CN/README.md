# diff_bench 文档

`diff_bench` 是 Luna-Flow MoonBit 包的差分正确性与性能基准仓库。

本仓库中的 `floating_vs_decmial_x` 仅作为 GitHub 上的可复现实验和实现参考，**不发布到 Mooncakes**，也不作为供下游依赖的运行时包。

## 结构

- `CONTRIBUTING.md`：贡献规则与发布检查清单
- `doc_standard.md`：文档要求
- `core/api.md`：导出 API 参考
- `core/tutorial.md`：使用教程
- `core/design.md`：实现与设计说明
- `floating_vs_decmial_x/api.md`：基准包 API 与运行入口
- `floating_vs_decmial_x/tutorial.md`：如何运行和复现实验
- `floating_vs_decmial_x/design.md`：基准设计、结果分析与实现对比报告
- `floating_vs_decmial_x/performance.md`：多语言性能分析报告
